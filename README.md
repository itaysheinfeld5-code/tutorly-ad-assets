וזו הדרך לצרף אותם בלי בורר קבצים ידני. אלה סרטוני שיווק שממילא מוצגים
לציבור כמודעות — אין בהם מידע פרטי, אין נתוני מורות ואין מספרי טלפון.

הקוד שמייצר אותם נמצא בפרויקט Remotion הנפרד ולא כאן.
